# Duplicate Hunter Brand System

## Concept: Precision Forensics

Duplicate Hunter deals with a sensitive task: identifying redundant files without making unsafe assumptions. Its identity therefore uses a **precision / verification** visual language rather than a generic cleanup or trash-can aesthetic.

The key motif is a pair of overlapping file cards joined by a checksum-style verification mark. It communicates three ideas at once:

- two files are candidates;
- content is verified, not guessed;
- the result remains under user control.

## Personality

- Precise
- Technical
- Calm
- Safety-conscious
- Local-first
- Productive rather than destructive

The project should feel like a trustworthy filesystem instrument, not an aggressive “cleaner”.

Signal Mint should remain the most recognizable accent. Warm Gold is reserved for caution, explicit action, and small status details rather than large surfaces.

## Logo

Primary asset: `assets/project-logo.svg`

The mark contains:

1. two overlapping file cards;
2. a hash/checksum construction;
3. a verified status mark;
4. a short baseline signal that reinforces the scanning motif.

### Usage

- Keep clear space around the outer rounded-square container.
- Do not recolor the verification mark red.
- Do not place the logo over visually noisy screenshots.
- At small sizes, use the logo alone without the project name.
- Do not replace the paired-file geometry with a trash-can icon; deletion is not the product promise.

## Typography

The artwork uses system-safe stacks so it remains portable in GitHub-rendered SVG:

- Latin: Inter / Segoe UI / Arial / sans-serif fallback
- Arabic: Tahoma / Segoe UI / Arial / sans-serif fallback
- Hash / technical data: ui-monospace / SFMono-Regular / Consolas / monospace fallback

Documentation itself should rely on GitHub's native typography.

## Graphic language

Recommended motifs:

- subtle technical grids;
- repeated paired shapes;
- checksum/hash fragments;
- thin signal lines;
- controlled rounded geometry;
- small status lights.

Avoid:

- generic broom or trash-can imagery;
- neon-heavy “hacker” styling;
- exaggerated cybersecurity shields;
- photos unrelated to filesystems;
- decorative complexity that competes with technical content.

## What makes this identity distinct

This identity is built around **verified duplication and reversible cleanup**, using graphite surfaces with mint/teal signals and a limited gold caution accent. It intentionally avoids the blue/coral document-recognition language used by OCR-focused projects and avoids generic storage-app visuals.
