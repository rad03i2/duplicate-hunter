# Contributing / المساهمة

Thanks for improving Duplicate Hunter. / شكرًا لمساهمتك في تطوير المشروع.

1. Fork the repository and create a focused branch.
2. Keep file operations safe-by-default; never introduce implicit deletion.
3. Add or update tests for behavioral changes.
4. Run `ruff check src tests` and `pytest`.
5. Update both English and Arabic README sections when user-facing behavior changes.
6. Open a concise pull request describing behavior and validation.

Please do not commit secrets, personal data, generated environments, or large test fixtures.
